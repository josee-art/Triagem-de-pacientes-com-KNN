\# Classificação de Diagnósticos Médicos com KNN



Este projeto utiliza Machine Learning para prever o diagnóstico de novos pacientes com base em um histórico de dados médicos catalogados. O algoritmo utilizado é o \*\*K-Nearest Neighbors (KNN)\*\*, que classifica os novos pacientes comparando suas características com as dos pacientes da base de treinamento.



\##Funcionalidades



\* Carregamento e exploração de dados médicos usando `pandas`.

\* Separação de dados em conjuntos de treino e teste.

\* Padronização de variáveis em mesma escala usando `StandardScaler`.

\* Treinamento de um modelo classificador KNN.

\* Previsão de diagnósticos para uma base de pacientes inéditos.
